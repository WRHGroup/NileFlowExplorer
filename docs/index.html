NileFlowExplorer

Simulated naturalized streamflow for the Nile Basin: historical (CHIRPS/CHIRTS, 1983–2014) and CMIP6 projections under SSP1-2.6, SSP2-4.5 and SSP5-8.5.

  1. Download the HDF5 naturalized-flow file to your computer: naturalized flow file (.h5) on Zenodo.
  2. Select that file with the “HDF5 flow file (.h5)” button below.
  3. Explore: click any element on the map (a sub-basin or a reach), or pick one from the list, to view its streamflow.

The sub-basin and reach maps load automatically from this site. All computation runs locally in your browser; your flow file is never uploaded.
